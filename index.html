Selected projects

Optimized Spatial Joins in Apache AsterixDB

I implemented optimized spatial join processing in Apache AsterixDB, an open-source distributed database.

Key contributions:

  • Implemented partition-based spatial merge joins.
  • Added spatial partitioning hints and optimizer rules for choosing the optimized join path.
  • Supported SQL++ spatial predicates including intersection, containment, and distance.
  • Added static and dynamic partitioning strategies, optimizer-plan tests, and runtime tests.

Our SIGSPATIAL 2026 paper evaluates a broader spatial integration effort. In a local synthetic benchmark, the optimized spatial join reduced median time from 151.056 seconds to 0.380 seconds compared with the same AsterixDB build with the spatial rewrite disabled.

R-Grove: Spatial Partitioning for Distributed Data Systems

I developed the R-Grove, R*-Grove and RR*-Grove indexes for Beast, an open-source geospatial processing system built on Apache Spark. We studied how R-tree techniques could be adapted to partition large spatial datasets across machines. The resulting Grove family includes R-Grove, R*-Grove, and RR*-Grove. These methods aim to produce spatially useful partitions while supporting distributed processing.

R*-Grove adapts R*-tree splitting techniques to improve partition quality and uses a balance factor to control differences in partition sizes. It can combine a sample with a storage-size histogram to account for records of different sizes. Our experiments evaluated partition quality and query performance on large spatial datasets.

Incremental Spatial Partitioning

I developed a framework for incrementally maintaining large spatial datasets. It supports bulk insertions and deletions while organizing data in distributed file-system blocks. Rather than rebuilding every partition, the framework selects partitions to reorganize within a given budget. I formalized this partition-selection problem and showed that it is NP-hard.

My cost model estimates range-query processing costs to guide reorganization as data changes. I implemented and compared three strategies inspired by R*-trees, LSM-trees, and cost-based optimization. Experiments on large real datasets evaluated partitioning time, query throughput, and partition quality.

Paper (PVLDB, 2022)Source code

Learned Query Optimizer for Spatial Join

I developed a learned query optimizer for distributed spatial joins. The project addresses the difficulty of choosing a join algorithm for datasets with different spatial distributions and partitioning. The models use dataset summaries and features describing the relationship between the join inputs. The initial optimizer estimates join cardinality and the number of candidate comparisons, and predicts which join algorithm to use.

My later framework extends this work to choose a partitioning strategy and tune the number of partitions and plane-sweep direction. I evaluated the models against baselines using synthetic and real spatial datasets. I also released datasets, code, and baseline models to support further research.

Learning-Based Spatial Partitioning

I developed a learning-based approach for choosing how to partition a spatial dataset. The goal was to select a suitable technique based on the input distribution without physically partitioning the dataset with every candidate method. In offline training, I generated datasets with diverse distributions and evaluated six partitioning techniques against four quality metrics. I summarized the datasets using histograms and measures of spatial skew, then trained models on those summaries and quality results.

For a new dataset, the trained model predicts a partitioning technique for a chosen quality metric. The accompanying code includes tools to prepare data, train models, and apply a selector with Beast. My experiments compared prediction accuracy with a baseline on synthetic and real spatial data.
