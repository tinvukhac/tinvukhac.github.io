Selected Projects

Optimized Spatial Joins in Apache AsterixDB. Implemented partition-based spatial merge joins, SQL++ spatial predicates, optimizer rules and partitioning hints, static and dynamic partitioning, and optimizer-plan and runtime tests. A local synthetic benchmark reduced median join time from 151.056 to 0.380 seconds against the same build with the spatial rewrite disabled.

R-Grove Spatial Indexes for Beast. Developed R-Grove, R*-Grove, and RR*-Grove indexes for Beast, a geospatial processing system built on Apache Spark. R*-Grove adapts R*-tree splitting and a balance factor to control partition sizes, and combines sampling with a storage-size histogram.

Incremental Spatial Partitioning. Developed a framework for bulk insertions and deletions with budgeted partition reorganization. Formalized the NP-hard partition-selection problem, implemented R*-tree, LSM-tree, and cost-based strategies, and evaluated query throughput and partition quality.

Learned Query Optimizer for Spatial Join. Developed models for join cardinality and candidate-comparison estimation, algorithm and partitioning selection, and execution parameter tuning. Evaluated the models against baselines on synthetic and real spatial datasets and released code and datasets.

Learning-Based Spatial Partitioning. Developed a model to select partitioning techniques from dataset summaries without executing each candidate method. Evaluated six techniques against four quality metrics using spatial histograms and measures of skew.
