# Tin Vu — personal website

A static personal site with no build step. Open `index.html` in a browser to preview it locally.

The biography, projects, and publications are based on the [previous UCR page](https://www.cs.ucr.edu/~tvu032/). The about section includes a short résumé-style timeline; add a current downloadable résumé when ready.

## Publishing to GitHub Pages

1. Create a GitHub repository named `tinvukhac.github.io` under the `tinvukhac` account.
2. Push these files to the repository's default branch.
3. In the repository's **Settings → Pages**, choose **Deploy from a branch**, select the default branch and `/ (root)`, and save.
4. Once deployment completes, visit `https://tinvukhac.github.io/`.

Edit `index.html` to update content and `style.css` to change the design. The site uses system fonts and has no external font dependency.
The profile photo in `images/tin-vu.jpg` comes from the previous UCR page and can be replaced with a newer photo.
